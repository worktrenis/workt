# Asset Store Google Play

Struttura cartelle e convenzioni per caricare velocemente gli screenshot.

Cartelle
- store/phone → screenshot telefono (1080x1920)
- store/tablet7 → screenshot tablet 7" (1200x1920)
- store/tablet10 → screenshot tablet 10" (1600x2560)

Nomenclatura consigliata
- phone-01.png … phone-08.png
- tablet7-01.png … tablet7-06.png
- tablet10-01.png … tablet10-06.png

Scene suggerite
1) Dashboard mensile
2) Inserimento ore (TimeEntry) con maggiorazioni
3) Impostazioni contratto/CCNL
4) Reperibilità e promemoria
5) Backup e ripristino
6) Info app e privacy

Linee guida
- PNG/JPG, lato min ≥320px, lato max ≤3840px
- Verticale consigliato per coerenza (9:16 circa)
- Niente dati personali reali
- Stessa lingua (IT) in tutte le schermate
